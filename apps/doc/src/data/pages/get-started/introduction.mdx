# Get started

Udixio UI is a framework-agnostic Material Design 3 component library: the same color/typography engine and component behavior ship as first-class packages for both **React** and **Angular**, on top of **Tailwind CSS v4**.

## Prerequisites

- Node.js ≥ 18
- Tailwind CSS v4 (`tailwindcss` `^4`) — Udixio's theme engine generates tokens that plug into Tailwind's CSS-first `@theme`
- A bundler Tailwind already integrates with (Vite, webpack, esbuild, Rollup) — used to generate the theme's static CSS at build time

## Pick your framework

| | |
|---|---|
| [**React**](/get-started/react) | Install `@udixio/ui-react`, mount `ThemeProvider`, render your first component |
| [**Angular**](/get-started/angular) | Install `@udixio/ui-angular`, wire the generated stylesheet, render your first component |
