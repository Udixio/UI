## Chip — aperçu et usage

Les Chips sont de petits composants interactifs qui représentent une action, un choix ou une entrée compacte. Ils suivent les principes de Material 3 et se déclinent en quatre grands types d’usage :

- Assist (déclenche une action rapide, proche d’un bouton)
- Filter (sélection on/off ou multi‑sélection)
- Input (représente une valeur saisie par l’utilisateur, ex. un tag)
- Suggestion (propose des options contextuelles)

Cette page explique comment utiliser `Chip` dans Udixio, avec des exemples pratiques. Le code du composant pourra évoluer, mais les concepts et bonnes pratiques restent valables.

## Installation et import

React :

```tsx
import { Chip } from '@udixio/ui-react';
```

Angular :

```ts
import { Chip } from '@udixio/ui-angular';
```

## États et accessibilité

- `disabled` rend le chip inactif.
- Les chips sélectionnables exposent `aria-pressed` automatiquement.
- Conservez une cible tactile d’au moins 48 dp et un contraste suffisant selon le thème.

## Chips (liste)

Le composant conteneur `Chips` ne supporte pas le mode `children`. Il rend exclusivement une liste à partir de `items` et notifie les changements via `onItemsChange` en React ou `itemsChange` en Angular.

Les contrats détaillés restent consultables séparément dans les références API de [`Chip`](/components/chip/api) et [`Chips`](/components/chips/api).

Un `id` applicatif stable est recommandé, notamment si les items sont réordonnés. Sans `id`, `Chips` conserve un identifiant interne lié à l’objet en React et utilise sa position en Angular.

<Code codes={{ react: chipsListReactSource, angular: chipsListAngularSource }}>
  <ChipsListReact slot="react" client:load />
  <ChipsListAngular slot="angular" client:load />
</Code>

`selected` transforme un item en filtre contrôlé. `removable` ajoute l’action de retrait en fin de chip. Un item qui ne déclare aucune de ces capacités reste une action compacte. Utilisez `scrollable` lorsque le défilement horizontal est préférable au retour à la ligne.

## Édition (variant="input")

- Double‑clic (ou F2/Enter quand le chip a le focus et n’est pas sélectionnable) met un chip en édition directement.
- L’édition est inline via `contenteditable` (pas de champ d’entrée séparé). Appuyez sur Enter pour valider, Échap pour annuler, ou sortez du focus pour valider.
- Si vous validez une étiquette vide sur un chip amovible, le chip est retiré.
- Les raccourcis existants demeurent: Enter/Espace pour la sélection, Retour/Suppr pour `onRemove` quand le chip est sélectionné et non en édition.

<Code
  codes={{ react: chipEditingReactSource, angular: chipEditingAngularSource }}
>
  <ChipEditingReact slot="react" client:load />
  <ChipEditingAngular slot="angular" client:load />
</Code>

Dans React, maintenir le focus pendant une seconde démarre également l’édition. Ce déclenchement différé n’existe pas dans Angular ; le double‑clic, F2 et Enter restent communs aux deux adaptateurs.

Avec `Chips variant="input"`, React permet en plus de cliquer dans une zone vide du conteneur pour créer un chip. Angular ne propose pas encore ce raccourci de création : ajoutez l’item dans votre logique applicative avant de l’éditer.
