## Usage

`Fab` represents the single primary action on a screen. Import it from
`@udixio/ui-react` or `@udixio/ui-angular`; `label` and `icon` are required.
The preview covers every color family, every supported size, extended labels,
and the disabled state.

<Code
  codes={{ react: fabActionsReactSource, angular: fabActionsAngularSource }}
>
  <FabActionsReact slot="react" client:load />
  <FabActionsAngular slot="angular" client:load />
</Code>

## Variants and sizes

Color families are `primary`, `secondary`, and `tertiary`, plus their
`primaryContainer`, `secondaryContainer`, and `tertiaryContainer` treatments.
Sizes are `small`, `medium`, and `large`.

`extended` reveals the label beside the icon. In compact mode, `label` remains
the accessible name without creating visible text.

## Link or action

Without `href`, the component renders a native button and defaults to
`type="button"`. With `href`, it renders a native link. Disabled links are
inert, receive `aria-disabled`, and leave the tab order.

Every size retains a 48 px target and a visible focus treatment. Positioning is
owned by the surrounding layout. Compose `Tooltip` explicitly if a compact FAB
needs additional visual help.

## Migrating to 3.0

| Before                         | 3.0                               |
| ------------------------------ | --------------------------------- |
| text `children` as the label   | required `label`                  |
| implicit tooltip               | compose `Tooltip` explicitly      |
| missing action type            | `type="button"` by default        |
| documented `variant="surface"` | use a supported container variant |
