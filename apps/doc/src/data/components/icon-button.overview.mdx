## Usage

`IconButton` represents a frequent action with one unambiguous icon. Import it
from `@udixio/ui-react`, `@udixio/ui-angular` or `@udixio/ui-svelte`.
`label` and `icon` are required: the icon stays decorative while the stable
label names the native control.

<Code
  codes={{
    react: iconButtonStatesReactSource,
    angular: iconButtonStatesAngularSource,
    svelte: iconButtonStatesSvelteSource,
  }}
>
  <IconButtonStatesReact slot="react" client:load />
  <IconButtonStatesAngular slot="angular" client:load />
  <IconButtonStatesSvelte slot="svelte" client:load />
</Code>

## Shape and width

`shape` selects the rounded or squared resting shape; `width` is `narrow`,
`default`, or `wide`. The shared Motion controller morphs the shape on
accepted presses by default. Set `shapeFeedback="none"` to keep it static.

  codes={{

## Toggle buttons

Set `toggleable` for binary actions such as Favorite. `pressed` is controlled;
`defaultPressed` initializes uncontrolled state. React emits
`onPressedChange`; Angular emits `pressedChange`; Svelte keeps
`onPressedChange` and also supports `bind:pressed`. `pressedIcon` optionally
replaces the resting icon while pressed.

Navigation links ignore toggle state. Use `aria-current` for the current
destination instead.

<Code
  codes={{
    react: iconButtonToggleReactSource,
    angular: iconButtonToggleAngularSource,
    svelte: iconButtonToggleSvelteSource,
  }}
>
  <IconButtonToggleReact slot="react" client:load />
  <IconButtonToggleAngular slot="angular" client:load />
  <IconButtonToggleSvelte slot="svelte" client:load />
</Code>

In Svelte, use a normal `bind:pressed` for the common case. To reject a
transition, use a function binding and only assign in its setter when the
owner accepts the new value.

## Accessibility

Action mode renders a native button with `type="button"` by default. `href`
switches to a native link. Disabled links lose their destination, receive
`aria-disabled`, and leave the tab order. Focus is visible and icons are
decorative.

The accessible `label` is also shown in a tooltip on hover and keyboard focus.
Set `tooltip` to a string to show different supporting text, or set it to
`false` when the surrounding interface already makes the action explicit.

## Migrating to 3.0

| Before                                | 3.0                                                   |
| ------------------------------------- | ----------------------------------------------------- |
| `iconSelected`                        | `pressedIcon`                                         |
| `activated`                           | `pressed` or `defaultPressed`                         |
| `onToggle`                            | `toggleable` plus `onPressedChange` / `pressedChange` |
| `allowShapeTransformation={false}`    | `shapeFeedback="none"`                                |
| text `children` as the label          | required `label` and `icon`                           |
| implicit tooltip from `title`/`label` | automatic `label`; customize or hide with `tooltip`   |
