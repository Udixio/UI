## Usage

Snackbars show a brief, non-blocking status message about an app process.
They render in normal document flow at the call site: fixed/bottom
positioning, stacking, and queueing multiple snackbars are the caller's
responsibility.

```bash
import { Snackbar } from "@udixio/ui-react"
```

<Code
  codes={{

</Code>

## Auto dismiss

Use `duration` (ms) to auto-close the snackbar; pass `onOpenChange` (React),
`openChange` (Angular), or use `bind:open` (Svelte) to control it.

  codes={{

## Controlled state

Use `open` with `onOpenChange` (React), `openChange` (Angular), or `bind:open`
(Svelte) for
controlled state; `defaultOpen` initializes uncontrolled state and defaults to
`true`.
