# R11 — Registre de choix de conception : surface d'écriture de @udixio/motion

Consolidation neutre de `M1-choix.md` à `M5-choix.md` (50 choix) et de `M1-annotations.md` à `M5-annotations.md` (5 × 40 annotations). Le fond n'est ni ajouté, ni retiré, ni reformulé. Les seuls textes produits sont les libellés de section, les résumés de variantes des groupes fusionnés, les notes de décision (« Option signalée », « Égalité ») et les critères ci-dessous.

**Bilan** : 22 choix conservés (12 ids gardés + 10 non fusionnés), 12 groupes de doublons retenus (28 ids fusionnés), 8 doublons proposés non retenus ou non appliqués (R1 à R8), 21 contradictions (11 ouvertes, 10 couvertes par une fusion retenue).

**Règles appliquées**
- Groupe retenu si au moins 2 experts proposent la même fusion, dans le même sens. Id gardé : majorité des experts proposeurs ; égalité : id le plus anciennement numéroté (ordre M1 < M2 < … < M5), signalée.
- Un id n'est absorbé qu'une fois. Une fusion dont la cible est elle-même absorbée n'est pas appliquée (R7, R8).
- Énoncé / Familles / Nature : repris tels quels du choix gardé. Variantes : une ligne par id fusionné, suivie de son décompte de verdicts.
- Avantages / Limites : texte original du choix gardé, suivi des points ajoutés en annotation, préfixés par l'expert (`[Mx]`). Les annotations portées par les ids fusionnés ne sont pas reprises ; leurs verdicts le sont.
- Conflits : union dédupliquée (champ d'origine et champs « conflits: » des annotations), hors id du bloc et ids fusionnés dans ce bloc. Seuls les identifiants sont retenus, repris tels qu'écrits dans les sources (références R10 sans « S » comprises, par exemple `M5-08` dans le champ Conflits de M5-S05).
- Verdicts : annotations reçues par l'id conservé, une par expert autre que l'auteur (4 par choix).
- Section 3 : paires dont une annotation désigne explicitement une incompatibilité (« contredit », « contre », « contraire à », « diverge », « brouille », « à trancher », « à arbitrer », « désaccord »). Les simples champs « conflits: » n'y figurent pas.
